The Hub - Izk
Private production workspace

A personal workspace for planning and making videos

The Hub - Izk is a private tool that runs on its owner's own computer. It keeps video projects, footage, review notes and reference material in one place.

This is not a public service. It has one user, its owner. There is no sign-up, and nobody else can use it.

How it uses YouTube

The owner can connect their own YouTube account so the app can collect reference videos for their projects. Access is read-only. The app reads:

  • the videos the owner has liked,
  • one playlist the owner names for reference material,
  • search results for a project the owner is working on.

It cannot upload, edit, delete, comment or change anything on YouTube. What it reads stays on the owner's computer. The details are in the privacy policy.
